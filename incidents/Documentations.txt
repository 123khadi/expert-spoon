RapidSOP - DC Office Mardan Control Room
Project Documentation - October 2026

1. PROJECT OVERVIEW:
RapidSOP is a real-time incident reporting system for District Control Room Mardan. Citizen reports Flood/Fire/Accident, DC Office sees it LIVE on Map.

URL: http://127.0.0.1:8000/dashboard/

3. FEATURES FOR VIVA:
- Citizen Form at / (Name, Email, Incident Type, Location, Description)
- Dashboard at /dashboard/ (Map + List)
- Admin Panel at /admin/
- SQLite Database (db.sqlite3)

4. TECHNOLOGIES:
Python, Django, Leaflet.js (OpenStreetMap), HTML, Bootstrap 5
